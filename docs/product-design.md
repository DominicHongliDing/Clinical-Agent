# Clinical Agent · 产品设计

更新于 2026-10-25。面向低年资及非精神科医生，让病例事实、医学依据与回答能在同一工作流程中核对，减少反复说明患者信息和整理 AI 输出的负担。

## 用户任务与页面结构

| 入口 | 用户完成的事 | 交互选择 |
| --- | --- | --- |
| 病例工作台 | 提问、补充、更正、阅读回答与引用 | 紧凑页头；发送反馈；侧栏和证据栏可收起；重要限制保留可见 |
| 病历库 | 找患者、分类筛选、打开 EHR、管理记录 | 头像卡片、姓名搜索、风险筛选、排序、归档及批量操作 |
| 患者病历 | 查看资料、填写模块、补充备注与更新 | 统一 EHR 入口；原文、AI 整理与医生确认分开；身份信息同步回聊天和列表 |
| 医生审计 | 选择答案、核对依据、保存复核意见 | 三步流程；病例与证据对照模型回答；领取后不跳回第一步 |

导航切换保持共同外壳、颜色和布局。病历输入统一进入 EHR，侧栏菜单用于重命名、置顶、归档等管理操作。任务执行记录作为辅助入口，避免与病例输入重复。

## 病例事实、证据与回答

1. **原始资料**保留原话、来源和时间。患者或用户报告不自动变成医生确认事实。
2. **更正与冲突**分别处理：明确更正进入后续回答，旧记录保留；不同来源相互冲突时并列展示，等待核实。
3. **上下文**按当前患者限定，保留病例事实和近期对话原文；接近预算才压缩旧对话，医学证据按需读取。
4. **依据**逐项对应主张和来源。服务端检查来源 ID 与引文原文，模型复核适用性，医生决定能否采用。
5. **回答**先回应本轮任务，详情可以展开。风险和关键限制保持可见，未知信息不能被推断为阴性。

病例事实、证据与回答风险的三个检查环节服务于修订和补查，而非仅在最后阻断回答。纯粹整理已知材料不强制医学检索；涉及临床依据时使用 RAG。资料不足时先完成可做的部分，说明具体缺口。

## 技能与工具调度

八类任务规则覆盖病例整理、鉴别评估、指南、用药安全、量表、风险、补充问诊与专科评估。模型可以按任务选择和组合技能、工具，在次数、时间与资源预算内循环；服务端负责权限、病例作用域、参数和结果上限。

本轮分层回答先落地病例整理与鉴别评估两个技能。完整任务使用 full 模式，简单补充、更正使用 update 模式；一次性篇幅要求不默认变成永久偏好。摘要、详情、限制与引用一并保存，旧答案保持原样。

RAG 使用查询改写、受控同义词、BM25 与百炼语义检索、RRF 融合、百炼重排。证据窗口不可变并保留版本，增量更新时旧索引仍可追溯。引文匹配只证明对应原文，不证明支持结论或人群适用性。

## 网页版与本地版

二者复用最新前端组件，数据和运行范围不同。

| 能力 | 个人网站 | 本地数据库版本 |
| --- | --- | --- |
| 病历库、EHR、紧凑聊天和折叠资料栏 | 已同步 | 已实现 |
| 预置病例 | 3 例虚构病例、6 份实际生成回答及引用 | 保留原记录，另新增虚构验收病例 |
| 新问题生成 | 个人 API Key 调用既有公开 BYOK 网关 | 本地完整自主 Agent、受限工具与百炼 RAG |
| 病例、回答与审计保存 | 当前浏览器 sessionStorage，刷新可恢复 | PostgreSQL 持久化，真实接口验收 |
| 医生审计 | 当前浏览器会话内三步交互与记录 | 数据库任务领取、提交与状态保存 |
| 身份与多人协作 | 访客体验，不是机构级独立复核 | 本地账号与角色；生产机构隔离等仍需单独验收 |
| 发布范围 | 仅更新网站前端；没有迁移本地完整后端 | 本轮工程通过，完整服务未发布到个人网站 |

线上个人 Key 仅保存在运行时内存中，不写入浏览器会话存储；刷新后需要重新连接。病例与审计数据属于当前浏览器会话，不能当作跨设备共享数据库。

## 异常与人工接手

| 情况 | 当前处理 | 需要核对的边界 |
| --- | --- | --- |
| 部分临床信息未知 | 整理已知内容，单列缺口与限制 | 未知不能写成无异常 |
| 更正到达生成过程中 | 记录输入版本并在最终保存前合并检查 | 不静默丢失，也不提升为已核实事实 |
| 证据不足或与问题不符 | 补查、修订或限制结论，保存检查状态 | 机器通过不等于医生批准 |
| 用户取消或连接断开 | 区分取消、部分完成、完成；按回执查状态 | 不盲目重复发起生成；外部调用可能仍产生用量 |
| 同机服务进程退出 | 识别中断，恢复已保存结果 | 不是持久 worker，不自动重放未完成调用 |

## 验收与下一步

本地已经用真实接口走通输入、补充更正、生成、医生审计提交、病例切换及刷新保存，并检查桌面和窄屏关键路径。网站另外完成会话适配、保存与浏览器检查。[版本记录](releases/2026-10-25.md)区分真实模型采样、确定性测试和界面检查。

独立医生仍需完成两技能评分、证据适用性与参考回答；RAG 独立标注尚未返回，不能宣称临床质量或排序指标改善。本轮未重测全部管理员页面、真实麦克风与附件，也没有真实临床试点。

长任务出现跨进程继续执行需求时，再实施持久 worker / checkpoint；偏好作用域独立存储仍待实现。机构身份、备份恢复、并发限流、密钥和告警等生产要求独立验收。
